# Ztrice releases

Ztrice is a real-time AI voice changer for Mac and Windows. This repository only hosts its installers and the files Ztrice uses to update itself. The source code is private.

## Download
Open the [latest release](https://github.com/maikama8/ztrice-releases/releases/latest) and download:
- **Mac** (macOS 12 or later, Intel or Apple Silicon): `Ztrice_<version>_universal.dmg`
- **Windows** (10 or 11, 64-bit): `Ztrice_<version>_x64-setup.exe`

Each release also has **Ztrice-Install-Guide.pdf**. It covers installing past the security warnings, setting up the virtual microphone (Ztrice Mic on Mac, VB-CABLE on Windows) and uninstalling.

Once installed, Ztrice checks this repository for new versions and offers to install them.

## Before you install
- **These builds aren't code-signed yet.** macOS and Windows warn the first time you open them; the install guide shows how to continue.
- **Ztrice is free while it's being tested.**
- **Use it responsibly.** Ztrice marks everything it converts with an AI watermark. Don't use it to impersonate real people or to deceive anyone.
